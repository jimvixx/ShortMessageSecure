# 🤝 Contributing to SMSecure

Thank you for your interest in contributing to SMSecure!

SMSecure is a privacy-focused SMS application built with modern Android tools and a clean, maintainable codebase. Contributions of all kinds are welcome.

---

## 🚀 Ways to Contribute

You can help improve SMSecure in several ways:

- 🐛 Reporting bugs  
- 💡 Suggesting new features  
- 🌍 Improving translations  
- 🧹 Refactoring and cleanup  
- 🔒 Security reviews  
- 📖 Documentation improvements  

---

## 🛠️ Development Setup

See BUILDING.md for full instructions.

Quick summary:

```bash
git clone https://github.com/jimvixx/ShortMessageSecure.git
```

Open the project in Android Studio and let Gradle sync.

---

## 🌿 Workflow

1. Fork the repository  
2. Create a feature branch:

```bash
git checkout -b feature/your-feature-name
```

3. Make your changes  
4. Test your changes  
5. Commit with clear messages  
6. Push to your fork  
7. Open a Pull Request  

---

## ✍️ Code Style

- Use modern Java (Java 17)  
- Keep code clean and readable  
- Prefer small, focused commits  
- Write comments in **English**  
- Follow existing project structure  

---

## 🧪 Testing

Before submitting a PR:

- Build the project successfully  
- Test on a real device or emulator  
- Verify core flows (sending/receiving messages, notifications, encryption)  

---

## 🌐 Translations

SMSecure uses a custom localization system:

- Base language: `res/values/strings.xml`  
- Use the `l10n_sync` tool  
- Do not manually edit translated files unless necessary  

---

## 🔒 Security

Security is critical for SMSecure.

If you discover a vulnerability:

- Do NOT open a public issue  
- Contact the maintainer privately (if possible)  
- Provide detailed reproduction steps  

---

## 📦 Pull Request Guidelines

- Keep PRs focused and minimal  
- Explain what and why, not just how  
- Link related issues if applicable  
- Avoid unrelated changes  

---

## ❌ What to Avoid

- Large unrelated refactors  
- Formatting-only commits  
- Adding unnecessary dependencies  
- Breaking backward compatibility without discussion  

---

## 💬 Communication

Be respectful and constructive.

This is an open-source project — collaboration matters more than perfection.

---

## ❤️ Thank You

Your contributions help keep SMSecure secure, modern, and useful for everyone.
