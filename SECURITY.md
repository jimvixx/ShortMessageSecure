# 🔒 Security Policy

## Reporting a Vulnerability

Security is critical for SMSecure.

If you discover a vulnerability:

- ❗ Do NOT open a public issue
- Use GitHub's **Report a vulnerability** feature in the repository's **Security** tab to disclose vulnerabilities privately.
- Provide:
  - Description of the issue
  - Steps to reproduce
  - Potential impact

---

## Scope

This project focuses on:

- SMS encryption
- Local data protection
- Identity verification

---

## Response

We aim to:
- Acknowledge reports quickly
- Investigate responsibly
- Provide fixes as soon as possible

Thank you for helping keep SMSecure secure.
