# 🤝 Code of Conduct

## Our Standards

We aim to build a respectful and collaborative community.

### Expected behavior:
- Be respectful and constructive
- Accept feedback gracefully
- Focus on improving the project

### Unacceptable behavior:
- Harassment or insults
- Discrimination
- Toxic or aggressive communication

---

## Enforcement

Project maintainers may remove or reject contributions that violate this code.

## Scope

This applies to:
- Issues
- Pull requests
- Discussions

---

## Summary

Be professional. Be respectful. Build something useful together.
