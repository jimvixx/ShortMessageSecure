💬 SMSecure — это мессенджер для обмена SMS-сообщениями на Android, ориентированный на конфиденциальность.

SMSecure — это форк проектов Silence/TextSecure, созданный для сохранения функциональности зашифрованных SMS на современных устройствах Android. Он сохраняет привычный интерфейс классического приложения для SMS, добавляя при этом инструменты для конфиденциальных переписок с подтверждёнными пользователями.

🔐 Зашифрованные SMS-переписки
Используйте SMS с сквозным шифрованием с совместимыми контактами. SMSecure использует протокол шифрования Signal для безопасных переписок, если обе стороны его поддерживают.

🛡️ Верификация личности
Проверяйте контакты с помощью QR-кодов или кодов безопасности, чтобы защититься от атак «человек посередине».

📱 Работает как обычное приложение для SMS
Отправляйте и получайте обычные SMS-сообщения без создания учётной записи, входа в систему или зависимости от централизованного сервиса обмена сообщениями.

🚫 Блокировка нежелательных сообщений
Блокируйте нежелательных отправителей, включая неизвестных или отправляющих буквенно-цифровые SMS, и держите свой почтовый ящик в порядке.

🔎 Поиск по перепискам
Быстро находите сообщения во всех переписках с помощью глобального поиска.

💾 Резервное копирование и восстановление
Создавайте и восстанавливайте резервные копии сообщений, чтобы всегда контролировать свою историю SMS.

🌍 Приоритет локального хранения
Сообщения обрабатываются на вашем устройстве. SMSecure не требует регистрации, не использует рекламу и не собирает данные пользователей.

⚠️ Важное примечание
Сквозное шифрование работает только в том случае, если обе стороны используют совместимое программное обеспечение. Обычные SMS-сообщения по-прежнему остаются обычными SMS и обрабатываются мобильной сетью.

🧩 Бесплатное программное обеспечение с открытым исходным кодом
SMSecure — это бесплатное программное обеспечение с открытым исходным кодом, лицензированное по GPLv3. Исходный код доступен для просмотра, аудита и внесения изменений.
